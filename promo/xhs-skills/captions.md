## 01 · 科普

图：card-01.png
标题：「AI 技能包」到底是什么？
正文：

最近 GitHub 上最火的不是模型，是「Skills」。

你可以把它理解成给 AI 的作业本：一个文件夹，里面放一份 SKILL.md，用大白话写清楚——遇到这类事，第一步做什么，第二步做什么，什么算做完。

它不神秘，也不是插件市场里的商品。它就是「把好用的做法写下来，交给 AI 照着做」。

没有 GitHub 账号也没关系。把仓库名发给你的 AI，让它自己去读，再让它挑一个适合你的装上。

第一期先讲清楚它是什么。后面两天，讲两个真正值得装的。

## 02 · 官方技能库

图：card-02.png
标题：官方 20 万星的 AI 技能库
正文：

anthropics/skills，官方开源的 Agent Skills 仓库，20 万星。

里面不是模型，是一份份「怎么做」的说明书：处理文档、做数据分析、写代码、整理资料。每一份都能直接读，也能让 AI 直接学。

对不写代码的人来说，它最大的价值不是「多了一个工具」，而是终于能看见：AI 是怎么被一步步教会的。

用法很简单：跟你的 AI 说「去读 anthropics/skills，挑一个能帮我干活的」。它读得比我们快。
